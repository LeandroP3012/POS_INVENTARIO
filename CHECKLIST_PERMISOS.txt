     ✅ ✓ Activar / ⊗ Desactivar (al seleccionar usuario)
     ✅ 📄 Exportar Excel (en la barra superior)

🧪 VALIDACIÓN AVANZADA (OPCIONAL PERO RECOMENDADO)

┌─────────────────────────────────────────────────────────────────────────┐
│ CREAR ROL DE PRUEBA: "Gerente de Personal"                              │
└─────────────────────────────────────────────────────────────────────────┘

  1. Ir a: Gestión de Roles
  2. Clic en: ➕ Nuevo Rol
  3. Datos:
     - Nombre: Gerente de Personal
     - Código: gerente_personal
     - Descripción: Puede ver y editar usuarios, cambiar estados
  
  4. Asignar SOLO estos permisos:
     ✅ users.view
     ✅ users.edit
     ✅ users.activate
     ✅ users.deactivate

  5. NO asignar:
     ❌ users.create
     ❌ users.delete
     ❌ users.export

  6. Guardar


┌─────────────────────────────────────────────────────────────────────────┐
│ CREAR USUARIO DE PRUEBA                                                 │
└─────────────────────────────────────────────────────────────────────────┘

  1. Ir a: Gestión de Usuarios
  2. Clic en: ➕ Nuevo Usuario
  3. Datos:
     - Usuario: prueba_permisos
     - Nombre: Prueba Permisos
     - Email: prueba@pos.com
     - Rol: Gerente de Personal
     - Contraseña: 1234
  4. Guardar


┌─────────────────────────────────────────────────────────────────────────┐
│ PROBAR PERMISOS                                                          │
└─────────────────────────────────────────────────────────────────────────┘

  1. Cerrar sesión (botón Salir)
  2. Login con:
     - Usuario: prueba_permisos
     - Contraseña: 1234

  3. Ir a: Gestión de Usuarios

  4. VERIFICAR QUE VE:
     ✅ Lista completa de usuarios
     ✅ Botón "✏️ Editar"
     ✅ Botón "✓ Activar / ⊗ Desactivar"

  5. VERIFICAR QUE NO VE:
     ❌ Botón "➕ Nuevo Usuario"
     ❌ Botón "🗑️ Eliminar"
     ❌ Botón "📄 Exportar Excel"

  6. Probar funcionalidad:
     - Seleccionar un usuario
     - Botón "✏️ Editar" debe habilitarse → Puede editar ✓
     - Botón "✓/⊗" debe habilitarse → Puede cambiar estado ✓
